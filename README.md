# Todo Motorhome

## `dashboard/`

Dashboard semanal de métricas de Todo Motorhome (sitio estático publicado con GitHub Pages):

**https://patriciobrunoar.github.io/todomotorhome/dashboard/**

- `dashboard/index.html`, `dashboard/assets/` – la página (filtro de fechas y comparación entre períodos).
- `dashboard/data/*.json` – solo conteos agregados (censo Supabase, Google Analytics, Sharetribe, Mailjet, Facebook, Instagram). No contiene datos personales ni credenciales.
- Los datos se actualizan una vez por semana.
